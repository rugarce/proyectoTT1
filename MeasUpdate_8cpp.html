Detailed Description

Implementación de la operación MeasUpdate.

Esta función implementa una única iteración de actualización de un filtro de Kalman para una medición escalar. Se calcula la ganancia de Kalman y se actualizan tanto el vector de estado como la matriz de covarianza del estado.
