Detailed Description

Implementación de la operación DEInteg.

Este integrador resuelve un sistema de ecuaciones diferenciales ordinarias de primer orden mediante un esquema de paso variable y orden variable, que adapta el paso para mantener los errores dentro de los límites tolerados.
