Detailed Description

Implementación de la función IERS que extrae/interpola parámetros de orientación de la Tierra.

A partir de una fecha UTC (MJD), busca la fila correspondiente en la tabla eopdata. Si se indica interpolación lineal ("l"), interpola entre la fila actual y la siguiente. En caso contrario ("n"), toma los valores directamente de la fila correspondiente. Devuelve los valores convertidos a radianes donde corresponde.

Note
Utiliza la constante SAT_Const::Arcs para convertir de arcosegundos a radianes.
La variable eopdata debe estar definida externamente como una matriz global.
Parameters
Mjd_UTCTiempo UTC en formato Modified Julian Date.
interpOpción de interpolación: "l" para lineal, "n" para sin interpolación.
Returns
Tupla con: x_pole, y_pole, UT1_UTC, LOD, dpsi, deps, dx_pole, dy_pole, TAI_UTC.
Exceptions
Finalizala ejecución si no se encuentra una fila correspondiente o si la interpolación falla.
